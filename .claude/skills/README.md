# Skills

Skills jsou znovupoužitelné instrukční sady pro Claude Code, které zapouzdřují specifický způsob práce nebo expertízu. Každý skill definuje, kdy a jak má Claude reagovat na určitý typ požadavku — například code review, generování testů nebo tvorbu dokumentace.

Skilly se spouštějí přes `Skill` tool a Claude Code je automaticky nabízí na základě kontextu konverzace.

## Šablona pro vytvoření skilu

Vzor pro nový skill najdeš v:

```
.claude/skills/skill-prompt-template.md
```
